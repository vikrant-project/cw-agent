# Troubleshooting CW Agent

| Symptom | Check | Response |
|---|---|---|
| Portal connection fails | TLS certificate, configured hostname, Caddy and loopback PHP service | Fix the deployment endpoint; retained tasks remain in the queue |
| Model profile unavailable | Profile login and shared admission lock | Authenticate the configured profile and inspect sanitized service evidence |
| Image provider reports 429/capacity | Native provider result and task counters | Respect provider limits; the controller permits one alternate existing account attempt |
| Invalid controller action | Current structured schema, role phase and CLI version | Preserve the real failure and repair compatibility; do not mark it successful |
| Reference repair rejected | Completed main-session `view_file` evidence | Ensure every actual staged reference was opened before delegation |
| Native raster missing | Explicit creation, actual artifact path, decoded bytes and export manifest | Fix the tool/export issue; cached references cannot stand in for new output |
| Image quality rejected | Current visual observations and original requirements | Use a native repair and new independent pixel checks |
| PowerPoint rendering fails | Trusted runtime, LibreOffice, Poppler, fonts and generated file | Fix the actual runtime/content failure and rerender all slides |
| Browser verifier fails | Chromium/OS dependencies, local server and fresh contexts | Fix the application or runtime based on executed evidence |
| WhatsApp disconnected | Per-user session state and unofficial connector compatibility | Reconnect the owner's account; keep session files private |
| Delivery uncertain | Notification state and actual received attachment | Investigate before resending to avoid duplicate delivery |
| Task needs attention | Exact error, remaining criteria and configured limits | Revise with concrete corrections or provide the missing capability |

Use `systemctl status` for the relevant service and inspect local logs privately. OAuth tokens, QR codes, passwords, message content and private URLs should not appear in public issues. Prompt changes cannot add an unavailable SDK, create provider quota or grant additional authorization.

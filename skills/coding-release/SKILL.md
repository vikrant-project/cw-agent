Prepare README.md with setup, usage, limitations, tests and integration requirements. Check the final tree and package readiness. Do not claim a public deployment or binary build that did not occur.


Goal-driven workflow: the AntiGravity accounts themselves understand, plan, create, test, review and repair the requested result. Follow AUTONOMOUS GOAL PROTOCOL. Intake defines goal, deliverables, all criteria and concrete specialist assignments. Tester maps every criterion to current evidence_ids with verify, including failures. Reviewer checks the original request and final files, then returns an explicit goal_achieved verdict with criterion-by-criterion reasons. Failed or stale checks cause repair and independent retesting, never a success claim. Task-specific playbooks improve execution; they do not override role permissions or evidence gates.
